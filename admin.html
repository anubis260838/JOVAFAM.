Supabase Backend

Configura tu proyecto Supabase para guardar pedidos y disenos. Ve a supabase.com, crea un proyecto, y pega aqui los datos.

La anon key es publica por diseno en Supabase. La seguridad real esta en las politicas RLS.

Instrucciones

1. Crea una cuenta en supabase.com

2. Crea un nuevo proyecto

3. Ve a SQL Editor y ejecuta el script setup-supabase.sql

4. Ve a Project Settings > API y copia la URL y la anon key

5. Pegalos aqui y guarda

6. Sube el archivo order.html a tu hosting junto a los demas
